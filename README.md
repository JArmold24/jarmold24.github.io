# Flag Football '94 web pages

The public pages for Flag Football '94, served by GitHub Pages at https://jarmold24.github.io/flag-football-94/:
a "coming to the App Store" page, support, privacy and the open-source licenses. The game itself is not published
here.

`flag-football-94/sw.js` retires the old offline copy of the web game in browsers that opened it before: it deletes
the cached game, unregisters itself and reloads the page.
